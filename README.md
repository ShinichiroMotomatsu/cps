# cps

## 新宿3D探索（`shinjuku3d.html`）

[Project PLATEAU](https://www.mlit.go.jp/plateau/)（国土交通省）の3D都市モデルをストリーミングで読み込み、
ブラウザだけで新宿の街を3D探索できるアプリです。ビルド不要・APIキー不要の単一HTMLファイルです。

### 起動方法

ローカルで簡易サーバーを立てて開くのが確実です:

```bash
cd cps
python3 -m http.server 8000
# → http://localhost:8000/shinjuku3d.html
```

GitHub Pages を有効にしている場合は `https://<ユーザー名>.github.io/cps/shinjuku3d.html` でも動きます。

### 機能

- **フライトモード** — マウスで自由に俯瞰。建物クリックで属性（建物ID・計測高さ等）を表示
- **ウォークモード** — WASD + マウスで一人称探索。段差判定つき（2m超の壁は登れない）、Shiftダッシュ、Spaceジャンプ
- **スポット移動** — 新宿駅 / 都庁 / 歌舞伎町 / 西新宿ビル群 / 新宿御苑へワンクリック
- **見た目切替** — リアル（航空写真＋昼）/ ネオン（深夜＋高さグラデーション発光）
- **画質切替** — LOD2テクスチャなし（推奨）/ LOD2テクスチャあり / LOD1。他都市のtileset.json URLの直接指定も可
- **コインラリー（ゲームプロトタイプ）** — 街に配置された15枚のコインをタイムアタックで収集

### データ出典

- 3D都市モデル: 国土交通省 Project PLATEAU（新宿区・3D Tiles配信、G空間情報センター / PLATEAU配信サービス）
- 背景地図: 国土地理院 地理院タイル（シームレス空中写真・淡色地図）

### ゲーム化のアイデア（今後の検討メモ）

- **タイムアタック系**: コインラリーの発展形。パルクール的に屋上を渡るコースを設計（現状のジャンプ＋段差判定で土台はある）
- **鬼ごっこ / かくれんぼ**: WebSocketでマルチプレイ化。ビルの陰・路地が天然の遮蔽物になる
- **タワーディフェンス / シム**: 建物クリックで取得できるPLATEAU属性（用途・高さ・築年など）をゲームパラメータに流用
- **謎解き・聖地巡礼**: 実在の街ならではの位置情報クイズ、ARチェックポイント
- 本格化するなら Three.js + [3d-tiles-renderer](https://github.com/NASA-AMMOS/3DTilesRendererJS) や Unity + PLATEAU SDK への移行も選択肢
